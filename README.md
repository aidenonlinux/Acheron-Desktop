# 🌌 Acheron Desktop (Normal Edition)

Welcome to **Acheron Desktop**, an extremely minimalist, bloat-free Linux distribution built on top of a barebones **Debian Linux** base. Named after the legendary Extreme Demon from Geometry Dash, this system is engineered for maximum performance, low input lag, and zero bullshit.

No Ubuntu bloatware, no heavy graphical animations. Pure performance.

## 🚀 Features
* **Base:** Debian Linux (Testing/Forky) – 100% stable and lightweight.
* **Window Manager:** Regolith Desktop (i3-tiling manager on a GNOME-backbone). Windows automatically tile neatly side-by-side.
* **Display Manager:** GDM3 (Clean and reliable login screen).
* **Gaming Ready:** Pre-configured with 32-bit architecture support, Steam installer, and NVIDIA drivers (optimized for cards like the GTX 980).
* **Essentials:** Pre-installed with Firefox, Nautilus File Manager, and PipeWire audio/video drivers.

## 🕹️ Essential Keybindings (Regolith)
Because Acheron Desktop uses a *tiling window manager*, you control the system mostly with your keyboard (the `Super` key is usually the Windows key on your keyboard):

* `Super + Enter` ➔ Open a new Terminal
* `Super + Space` ➔ Open the App Menu (to search and launch apps like Firefox)
* `Super + Shift + Q` ➔ Close the active window
* `Super + [Arrow Keys]` ➔ Navigate between open windows
* `Super + Shift + E` ➔ Log out / Shut down the system
